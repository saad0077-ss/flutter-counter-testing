# Flutter Counter Testing

A beginner-friendly Flutter Counter Application built to understand and practice automated testing in Flutter.

### Features
- Increment and decrement counter.
- Unit Testing for counter logic.
- Widget Testing for UI interactions.
- Test organization using `group()` and `test()`.

### Testing
Run all tests using:

```bash
flutter test
```

### Technologies
- Flutter
- Dart
- flutter_test

### Learning Purpose
Understanding Unit Testing, Widget Testing, test cases, assertions, and automated testing practices in Flutter.
